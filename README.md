# 🚀 ফেসবুক পেজ স্মার্ট অটোমেশন বট (Meta Graph API + Gemini AI + Google Sheets)

একটি শক্তিশালী ও আধুনিক ফেসবুক বিজনেস অটোমেশন সিস্টেম, যা আপনার পেজের কাস্টমারদের কমেন্টে স্বয়ংক্রিয় ও বুদ্ধিমান উত্তর দেয়, ইনবক্সে পণ্যের বিবরণ ও মূল্য পাঠায় (Private Reply), মেসেঞ্জারে স্বাভাবিক চ্যাট করে প্রশ্নের উত্তর দেয় এবং সরাসরি ক্যাশ অন ডেলিভারি (COD) অর্ডার নিয়ে আপনার **Google Sheet**-এ সেভ করে।

---

## ✨ প্রধান ফিচারসমূহ

1. **বুদ্ধিমান কমেন্ট হ্যান্ডলিং (AI Comment Reply):**
   - কাস্টমারের কমেন্টের অর্থ বুঝে বাংলায় সুন্দর উত্তর দেয়।
   - দাম, সাইজ বা বিস্তারিত জানতে চাইলে সরাসরি কমেন্টে উত্তর দেওয়ার পাশাপাশি ইনবক্সে মেসেজ পাঠায়।
   - মেটার স্প্যাম পলিসি এড়াতে প্রতিটি কমেন্টে ভিন্ন ও প্রাসঙ্গিক ভাষায় রিপ্লাই তৈরি করে।
2. **ইনবক্স প্রাইভেট রিপ্লাই (Private Reply from Comment):**
   - কোনো কাস্টমার পোস্টের নিচে কমেন্ট করলে স্বয়ংক্রিয়ভাবে তার মেসেঞ্জারে বিস্তারিত প্রডাক্ট লিস্ট ও অর্ডার লিংক পৌঁছে দেয়।
3. **মেসেঞ্জার স্মার্ট চ্যাটবট:**
   - বাংলা, বাংলিশ বা ইংরেজিতে কাস্টমারের সব প্রশ্নের প্রাঞ্জল উত্তর দেয়।
   - গুগল শিট থেকে রিয়েল-টাইমে পণ্যের দাম ও স্টক যাচাই করে জানায়।
4. **স্বয়ংক্রিয় অর্ডার সংগ্রহ ও ভ্যালিডেশন:**
   - কাস্টমারের নাম, সচল ১১ ডিজিটের মোবাইল নম্বর এবং পূর্ণাঙ্গ ঠিকানা সংগ্রহ করে।
   - সঠিক মোবাইল নম্বর নিশ্চিত করে Google Sheet-এর "Orders" ট্যাবে নতুন অর্ডার এন্ট্রি করে।

## 📊 Google Sheets সংযোগ করার নিয়ম

১. **Google Cloud Console** (https://console.cloud.google.com)-এ যান।
২. একটি নতুন প্রোজেক্ট তৈরি করুন এবং **Google Drive API** ও **Google Sheets API** এনাবল (Enable) করুন।
৩. **Credentials** সেকশন থেকে একটি **Service Account** তৈরি করে তার একটি `JSON Key` ডাউনলোড করুন।
৪. ডাউনলোড করা ফাইলের নাম পরিবর্তন করে প্রজেক্ট ফোল্ডারে `service_account.json` নামে রাখুন।
৫. আপনার গুগল শিটে যান এবং সার্ভিস অ্যাকাউন্টের ইমেইলটিতে (যা JSON ফাইলের ভিতর `client_email` নামে থাকে) শিটের **Editor** পারমিশন দিয়ে শেয়ার করুন।
৬. আপনার গুগল শিটে দুটি ট্যাব/শীট রাখুন:
   - **`Products`** (কলাম হেডার: `name`, `price`, `stock`, `description`)
   - **`Orders`** (বট নিজে থেকেই নতুন অর্ডারের রো যোগ করবে)
৭. `.env` ফাইলে আপনার গুগল শিটের আইডি বসিয়ে দিন।

## 🌐 Meta for Developers ও Facebook App সেটআপ

১. **[developers.facebook.com](https://developers.facebook.com)**-এ গিয়ে লগইন করে **My Apps** > **Create App** চাপুন।
২. অ্যাপ টাইপ হিসেবে **Business** বা **Other** সিলেক্ট করুন।
৩. অ্যাপ ড্যাশবোর্ড থেকে **Messenger** এবং **Webhooks** প্রোডাক্ট যোগ করুন।
৪. **Page Access Token সংগ্রহ:**
   - Messenger Settings > **Generate Access Token**-এ গিয়ে আপনার পেজটি সিলেক্ট করে টোকেন জেনারেট করে কপি করুন।
   - প্রয়োজনীয় পারমিশন: `pages_messaging`, `pages_manage_posts`, `pages_read_engagement`, `pages_show_list`।
৫. `.env` ফাইল তৈরি করুন:
   - `.env.example` ফাইলটিকে কপি করে নাম দিন `.env`
   - সেখানে আপনার `PAGE_ACCESS_TOKEN`, `VERIFY_TOKEN`, এবং `PAGE_ID` বসিয়ে দিন।

## 💻 লোকাল সার্ভার ও লাইভ ওয়েববুক রান করা

### ধাপ ১: সার্ভার চালু করুন
```bash
python main.py
```
*(সার্ভারটি `http://localhost:8000`-এ চালু হবে।)*

### ধাপ ২: ngrok দিয়ে লাইভ পাবলিক URL তৈরি করুন
মেটা লোকালহোস্টে ওয়েববুক পাঠাতে পারে না, তাই একটি ফ্রি HTTPS লিংক প্রয়োজন:
```bash
ngrok http 8000
```
ngrok আপনাকে একটি লিংক দেবে, যেমন: `https://abcd-1234.ngrok-free.app`

### ধাপ ৩: মেটায় ওয়েববুক কনফিগার করুন
১. Facebook Developer অ্যাপে **Webhooks** সেকশনে যান।
২. **Callback URL** দিন: `https://abcd-1234.ngrok-free.app/webhook`
3. **Verify Token** দিন: `.env` ফাইলে আপনি যে `VERIFY_TOKEN` লিখেছেন সেটি।
4. "Verify and Save" চাপুন।
5. পেজ সাবস্ক্রিপশনে নিচের ফিল্ডগুলো সাবস্ক্রাইব করুন:
   - `messages` (ইনবক্স মেসেজের জন্য)
   - `messaging_postbacks` (বাটনের জন্য)
   - `feed` (পেজের পোস্টের কমেন্ট পাওয়ার জন্য)

## ☁️ ক্লাউডে ২৪/৭ ফ্রি ডেপ্লয়মেন্ট

কম্পিউটার বন্ধ থাকলেও যেন বট ২৪ ঘণ্টা চালু থাকে, তার জন্য আপনি ফ্রিতে [Render.com](https://render.com) বা [Railway.app](https://railway.app)-এ ডেপ্লয় করতে পারেন:
1. গিটহাবে এই প্রজেক্ট পুশ করুন।
2. Render-এ গিয়ে "New Web Service" খুলে রিপোজিটরি সিলেক্ট করুন।
3. Build Command: `pip install -r requirements.txt`
4. Start Command: `uvicorn main:app --host 0.0.0.0 --port $PORT`
5. Environment Variables-এ `.env`-এর ভ্যালুগুলো যোগ করে দিন।
6. Render আপনাকে একটি পারমানেন্ট HTTPS URL দেবে, যা আপনি মেটার ওয়েববুকে বসিয়ে দেবেন।
